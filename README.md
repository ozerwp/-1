# 实验1：课程基础与实验环境搭建

## 实验概述
本实验是软件工程课程的第一个实验，主要目的是熟悉工具链，理解实验体系与软件工程流程。

## 核心任务
1. 安装配置相关工具（编程工具、Git、IDE、建模工具）
2. 注册GitHub账号，创建实验仓库
3. 编写"Hello World"程序并提交至仓库
4. 阅读《软件工程》课程第一章节，自主选题，确定课程设计主题
5. 安排软件工程课程设计流程，撰写初步的实验计划

## 实验内容

### 1. Hello World程序
使用Python编写的简单Hello World程序：
```python
print("Hello, World!")
```

### 2. 课程设计主题
选择了**图书管理系统**作为课程设计主题，该系统包含用户管理、图书管理、借阅管理等核心功能。

### 3. 实验计划
详细的实验计划见`实验计划.md`文件，包含：
- 个人学习目标
- 时间分配
- 工具清单
- 后续实验安排

## 工具清单
- 编程语言：Python 3.10+
- 版本控制：Git 2.30+
- IDE：VS Code
- 建模工具：PlantUML
- 文档工具：Markdown

## 运行说明
1. 确保安装了Python 3.10+
2. 在命令行中执行：
   ```
   python hello.py
   ```
3. 预期输出：
   ```
   Hello, World!
   ```
